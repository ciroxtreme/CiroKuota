# CiroKuota 🛡️
Minimalist Wi-Fi Quota Saver & Habit Blocker for Android.

Built specifically for Tuan Ciro to prevent excessive Wi-Fi consumption from adult video streaming and endless Instagram scrolling.

## Fitur Utama
1. **Wi-Fi Quota Tracker & Daily Budget:** Pemantau pemakaian data Wi-Fi real-time dengan batas budget harian yang fleksibel.
2. **Local VPN Killswitch & Family DNS Shield:** Memutus koneksi data seketika saat darurat / kuota habis, serta memfilter domain dewasa via Cloudflare Family DNS (`1.1.1.3`).
3. **Aggressive AppLock & Session Limiter:** Membatasi waktu scrolling Instagram dan nonton video di browser web per sesi.
4. **Clean Monochrome & Minimalist Jetpack Compose UI:** Desain estetik, ringan (~25 MB RAM), dan tanpa Device Admin.
